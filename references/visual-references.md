# Visual References: Benchmarks por Tipo de Página

Curadoria de páginas reais, organizadas por tipo. Usar no **Step 1 (DIRECIONAR)** antes de escolher paleta, layout e estilo.

**Como usar:** Antes de buildar, abrir 2-3 referências do tipo correto. Identificar o padrão visual dominante e usar como norte, não copiar, mas absorver o nível de qualidade e decisões de layout.

**Regra atualizada:**
- **Hugeicons** como biblioteca primária em landing pages que precisam de expressividade visual
- **Lucide** para dashboards e UI de produtos onde consistência > variedade

### Estilos disponíveis no Hugeicons
```
Stroke Rounded   ← padrão mais usado, clean e moderno
Twotone Rounded  ← dois tons, bom para ícones destacados
Duotone Rounded  ← gradiente interno, premium
Solid Rounded    ← ícones preenchidos, boa legibilidade
Bulk Rounded     ← ícones com peso visual maior
Stroke Standard  ← sem arredondamento
Solid Standard   ← sem arredondamento, preenchido
Stroke Sharp     ← arestas, mais técnico
Solid Sharp      ← arestas + sólido
```

## Como Usar Estas Referências no Workflow

### No Step 1 (DIRECIONAR):

```
1. Identificar o TIPO de página (sales, capture, challenge, vsl, institutional)
2. Abrir 2-3 referências da tabela correta
3. Para cada referência, anotar:
   - Paleta dominante (bg, text, accent)
   - Font pairing (display + body)
   - Layout do hero (split? centered? fullscreen?)
   - 1 elemento "wow" que mais impacta
4. Usar como inspiração para o Step 1.1 (Paleta Visual)
5. NÃO copiar, absorver o nível de qualidade e adaptar ao contexto
```
